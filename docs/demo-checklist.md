# Demo Checklist

Use this flow for a concise product walkthrough and README screenshots.

1. Open the landing page and highlight the distinct StreamSphere identity and AI discovery panel.
2. Register a new account or sign in.
3. Browse `/movies`, then search, filter by genre, and paginate.
4. Open a movie detail page and show its genres, rating, summary, and reviews.
5. Add the movie to favorites and watchlist, submit a rating, and publish a review.
6. Return home to show recommendations, trending titles, continue watching, and popular genres.
7. Run an AI search using a natural-language request and point out the explanation and confidence result.
8. Open notifications to show live WebSocket delivery or the REST fallback.
9. Open `/profile` to show saved movies, recent reviews, and viewer insights.
10. Sign in as an administrator and visit `/admin` for moderation and platform analytics.
11. Open `/health`, `/metrics`, and `/docs` to show operational and API visibility.

Suggested README screenshots: landing/AI search, catalog filters, movie detail engagement, profile insights, and admin analytics. Use only seeded demo content and avoid screenshots containing personal email addresses or tokens.
